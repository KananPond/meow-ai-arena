# Results and per-game records

Generated by the final event script (`../tournament/tourney.py`), refitted after Mercury's added games on 10-20. Short names map to models in [the bot index](../bots/README_en.md). Absolute paths on the organizer's PC in tables, statistics and JSON were replaced with repository-relative paths or `<…>` placeholders; everything else matches the originals.

| File | Contents |
|---|---|
| `RESULTS_正式榜.md` | **Official board** (10 official contestants): totals, intervals, rank intervals, pairwise differences, adjacent places, ratings by game type, 1v1 vs. hard sparring, compilation and timeouts, time used, schedule and sources, supplementary old rank-point scoring |
| `RESULTS_强对手榜.md` | **Strong-opponent board** (adds 2 reference contestants and the hard sparring line); same structure, plus comparison against the sparring line |
| `视频统计_正式榜.md`, `视频统计_强对手榜.md` (and `.json`) | Per-type in-game statistics: sole first places, survival turns, opponents crashing into trails, contested-cell wins/losses and death causes. Formal-mode games only, excluding imported fast previews: a different game set from the overall scores |
| `results.json` | Both boards, machine-readable: each contestant's total, components, intervals, pairwise differences and rank intervals in `boards.<board>.score` |
| `results.jsonl.gz` | The 1446 added games on 10-20, one per line, with per-turn `moves` |
| `预览并入.jsonl.gz` | Other imported games: 4267 from the 10-18 final (`source = final1018`) and two fast-mode previews (`preview1`, `preview2`), one per line |
| `清单.json` | Frozen at final start: engine/referee hashes, compiler version/flags and each program's source hash |
| `程序.json` | Origin, source hash and compiled-binary hash for every program |

Per-game fields: game `gid`, `type` (`1v1`, `3p`, `4p`, `12p`), player count `n`, map `seed`, `seats` (seat 0 first), `rank` (0-based, same-turn deaths tie), rank-point `score`, `turns`, `death_turn` (−1 = survived), `cause` (`alive`, `out`, `obstacle`, `self`, `trail`, `headon`: survived, off-board, obstacle, own trail, another trail, lost contested cell), CPU usage `first_ms`, `avg_ms`, `max_ms`, over-budget turns `timeouts`, `invalid` output, `crash_turn`, `board`, bootstrap `block`, `source`.

To replay a game, use `python arena.py play PROGRAM_A PROGRAM_B … --seed MAP_SEED` in `../workspace/`, listing programs in `seats` order; the number listed sets player count. Use `greedy` and `sparring_hard` by name, and `greedy` for `greedy_fill`. Bots independent of time reproduce turn for turn; search using `budget_left()` varies slightly with machine state.

- Fast previews were played before the race (10-17) for a rough view. Fast mode records overruns without penalties, so entire preview games containing overruns were discarded. Their `3p` games do not count (the final has no 3-player games).
- Both boards share 1v1 games and have separate multiplayer games. A contestant's scores across boards are not comparable.
- Tables saying map seeds are in an unpublished `赛程.json` reflect the contest-time wording. Both final schedules are now published: `../tournament/赛程_1018终场.json` and `../tournament/赛程_1020补打.json`.
