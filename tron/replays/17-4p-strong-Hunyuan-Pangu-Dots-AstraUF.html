松开鼠标载入回放







  
快捷键

  

    
空格 / K播放 / 暂停（在终局时从头播放）

    
← →上一回合 / 下一回合；按住 Shift 一次 10 回合

    
Home End开局 / 终局

    
[ ]　, .上一个 / 下一个事件（出局、抢格、互换）

    
+ -加速 / 减速（0.25× ～ 8×，1× = 每秒 4 回合）

    
G跳到某回合（光标进回合输入框，输入后回车）

    
R录屏模式：只留棋盘和记分板，16:9。再按 R 或 Esc 退出

    
V地盘：空格染成最先能到达它的活人的颜色（同时到达的不染）

    
T棋盘上的事件字幕

    
E终局时收起 / 显示名次表

    
0–9 A B聚焦某个座位（别人的轨迹变暗），再按一次取消；也可以点右栏

    
F全屏

    
O打开文件

    
H / ?这张帮助

  

  
地址栏参数（viewer.html?file=replays/a.json&turn=40&rec=1，写在 # 后面也行）

  

    
file=路径载入这个回放（相对 viewer.html）。浏览器默认不许网页读本地文件：Edge / Chrome 要加启动参数 --allow-file-access-from-files，或者在 workspace 里运行 python -m http.server 后打开 http://localhost:8000/viewer.html?file=…

    
turn=N停在第 N 回合结算后（N 个回合已经走完）

    
p=0.5和 turn 一起用：停在第 N 回合这一步走到一半的地方（0～1）

    
play=1打开就播放（从 turn 开始）

    
speed=2速度倍数：0.25、0.5、1、2、4、8

    
rec=1录屏模式

    
vor=1显示地盘

    
focus=3聚焦 3 号

    
toast=0不显示事件字幕

    
end=0终局不弹名次表

    
check=1自检：把网页重算的 turns、rank、death_turn、cause、final、score 和回放逐项核对，结果显示在顶栏（不一致时页面顶上是红条）

  

  
画面

  
方块的颜色就是座位；亮色发光、写着编号的方块是活人的头，暗底带 × 的是死者停下的地方；同色的线是轨迹（永久是墙）；空心方框是出生点；灰块是障碍。
  "回合 N"表示已经结算完 N 个回合，所以第 t 回合出局的人在"回合 t+1"时才显示为出局。时间轴上排的金色菱形是抢格、蓝色是互换位置，下排是出局（颜色是座位）。点标记跳到那一回合结算后。
