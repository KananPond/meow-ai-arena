# team3 B：豆包 Doubao-Seed-Evolving

**复盘（约 290 字）**

1. **最对的决定**：战术会议就钉死"相同确定性截球函数 + MSG bit7 同步角色"的 C/D 动态分工协议，两人独立实现也能配合，不依赖临场协调。

2. **最大失误**：我上半场的角色判定把踢球 cd 算进截球时间，导致刚踢完球的 C 立刻被夺权、角色逐帧翻转，空门频出；根因是只凭推演没先跑最小回放验证。

3. **分工配合**：纯协议协作——会议约定同一套选举/踢球打分规格，各自写代码；队友中途通过 tc.py 精准指出我 steer 斜向饱和和 D 过早前压两个 bug，是全队止跌的关键。

4. **评价队友**：强，工程诊断一针见血、个人赛第 3 实至名归；不足是协议里带滞回状态，两人对称实现时易出双翻，无状态选举更稳。

5. **时间分配**：几乎全压在团队 player.cpp（队友强、团队分确定），partner.cpp 完全没写——这是失误：个人分占一半且只需复用打磨，却只得第 10。

6. **重来会提**：先做"无状态、无 IDX、无记忆"的最简纯函数球员，留 10 分钟先验证双开自配对 baseline，再谈复杂踢球搜索。
