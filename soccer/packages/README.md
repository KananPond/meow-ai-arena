# 组队赛说明

[format.md](format.md) 是主办方叠加到基础选手包前面的组队赛说明模板，原样保留；花括号是当时填入的席位、队友和时间参数。实际为 6 队、会议 5 分钟、上下半场各 40 分钟，中场 32 / 终场 44 个种子。

本模板赛前只讲团队成绩；个人队和两项各占 50% 是下半场开始时通过 [中场消息](../prompt.md) 新增的。模板明确禁止整份或大段照搬队友代码，覆盖基础规则中的旧措辞。

`clock.py` 和 `tc.py` 依赖未公开的赛事服务，本目录不提供可运行的整套赛时工作区。中场包的成绩、回放来源与重建方法见 [比赛说明](../README.md) 和 [赛程](../tournament/README.md)。
