# 队内沟通工具（选手版）

你和队友在同一段时间里各自开发，最后各负责一名球员。你们只能通过下面这个小工具交流。
你的目录下有 `tc.py`（和 `tc.bat`），在你的目录里运行即可，不用传身份。

## 命令

| 命令 | 作用 |
|---|---|
| `python tc.py send "消息"` | 发消息给队友 |
| `python tc.py send -f msg.txt` | 从文件发长消息（多行、含代码都行） |
| `python tc.py send -` | 从标准输入读（管道也可以） |
| `python tc.py inbox` | 看未读消息，看完自动标记已读 |
| `python tc.py wait 60` | 阻塞等队友新消息，有就立刻返回；不写秒数默认 120，最多 600 |
| `python tc.py log` | 看最近 20 条历史；`log --last 50` 更多；`log --all` 全部 |
| `python tc.py status` | 未读数、队友最后发言时间 |

（`tc.bat` 等价于 `python tc.py`，Windows 下可以直接写 `tc send "..."`。）

## 约定

- **队友的代码目录你可以读，不要改**。路径用 `status` 查看。你自己的目录随便写。
- 想要队友回复时，发完消息后用 `wait`；不要空转轮询。等不到就继续干活，过一阵再 `inbox`。
- 消息尽量具体：接口约定、参数含义、你打算怎么配合、你的代码在哪个文件。长内容写进文件，消息里给路径。
- 聊天记录会被完整保存，不能删除或修改；请不要尝试编辑 `chat` 目录里的任何文件。
- 编译、跑对局、复盘等工具输出末尾如果出现
  `[组队消息] 你有 N 条队友未读消息，运行 … 查看`，说明队友给你留言了，请及时 `inbox`。

## 在你自己的脚本里加提醒（可选）

```python
import tc      # tc.py 与脚本同目录
...            # 正常输出
tc.notify()    # 有未读才多输出一行
```

或者不改脚本，用包装：`python with_notice.py g++ -O2 -o me.exe me.cpp`。

## 常见问题

- 中文乱码：默认输出 UTF-8；管道里发中文请用 `send -f 文件`（UTF-8 或 GBK 文件都能读）。
- 消息以 `-` 开头：写成 `send -- "-开头的消息"`。
