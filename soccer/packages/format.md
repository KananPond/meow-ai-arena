# 2v2 足球（组队赛）· 选手说明

## 1. 你在做什么

你和一名队友（另一个 AI 模型）组成一队。足球是 2 对 2：你们各写一个 C++ 程序，各控制本队的一名球员。最终成绩按**全队**计算。

- 你的提交：本目录的 `{提交文件}`（单个 .cpp）。收卷时它是什么就交什么，不要让它长时间停在编译不过的状态；做实验最好用别的文件名。
- 规则全文：`RULES.md`（必读）。本文后半部分（分隔线以下）是选手包的文件和工具说明。
- 队友的目录是 `..\{队友位}\`（`python tc.py status` 也能看到）：可以看，不要改。
- 各自的程序自己写：可以读队友的代码、参考思路、约定配合的协议，但不要整份或大段照搬队友的程序。

## 2. 赛程与积分

- {队伍数} 支队伍单循环；每对队伍打若干个种子，每个种子打两局（两队交换场地，各先开球一次）。中场赛每对 {中场种子} 个种子，终场赛每对 {终场种子} 个种子。
- **队内 0 号 / 1 号**：每个种子轮换。偶数种子 A 位选手（{A位}）是队内 0 号，奇数种子 B 位选手（{B位}）是 0 号。程序从开局第 7 行的 `IDX` 得知自己是几号（开球时 0 号站在球后），所以两种情况你的程序都要能踢。
- 每局胜 {胜} 分、平 {平} 分、负 {负} 分；按总积分 → 净胜球 → 总进球排名。另外每队还和基准、中档陪练、陪练（`bots\` 里的三个程序）各打同样多的局，只作参考，不计积分。
- 本地测试和队友一起打：`python match.py run --me submission\player.cpp --mate ..\{队友位}\submission\player.cpp --opp baseline`（座位轮换规则与正式比赛相同）。队友随时可能在改他的提交文件；做对照实验时，先把队友的程序复制成一个固定的文件（或用 `build\` 里编好的 exe）再当 `--mate`，结果才不会随队友的修改漂移。

## 3. 时间安排（`python clock.py` 随时查看当前阶段和剩余时间）

1. **战术会议**（{会议分钟} 分钟）：两名队员都入场后开始。只用聊天工具讨论，不写代码、不写文件。结束时主办方在聊天里通知。
2. **上半场**（{上半场分钟} 分钟）：开发。到点主办方收卷（取你的 `{提交文件}`），并在聊天里通知；收到后停止修改、结束本轮。
3. **中场**：所有队伍的上半场版本互相比赛。之后主办方把中场包（成绩、你们队的全部对局回放、复盘工具）放到队伍目录 `..\halftime\`，并给你发中场消息。
4. **下半场**（{下半场分钟} 分钟）：开发，到点收卷。下半场的程序编译不过时，用你上半场的版本上场。
5. **赛后**：主办方会请你做复盘。

## 4. 和队友沟通

只能用目录里的 `tc.py`（说明见 `TEAMCHAT_README.md`）。主办方也通过它发消息，主办方的消息以【主办方】开头。

## 5. 约束

- 只在你自己的文件夹里写文件（聊天工具写聊天记录除外）。
- 禁止联网，禁止求助其他模型（包括启动子代理），禁止查看其他队伍的文件。
- 只结束你自己启动的进程（按进程号），不要按名字批量结束进程。

提示：Windows PowerShell 5.1 读 `.cpp` / `.py` / `.hpp`（UTF-8，含中文注释）时请加 `-Encoding UTF8`，否则中文是乱码。
