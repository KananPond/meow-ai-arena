# Results and per-game records

All three tournaments ran through `../tournament/tournament.py`, which also generated the result tables (`成绩.md` and `成绩.json` are the originals). Short names map to models in [the bot index](../bots/README_en.md).

| Path | Contents |
|---|---|
| `final/` | **Final tournament**: 14 second-half versions + baseline + organizer's reference, 60 maps, 14400 games; determines the final places |
| `halftime/` | **Half-time tournament**: 14 first-half versions + baseline + organizer's reference, 42 maps, 10080 games. Its table was included in the half-time package |
| `progress/` | **Progress tournament**: each second-half version plays the pool of all first-half versions + baseline, 8 maps, 3360 games. No separate standings; used in the supplementary tables |
| `附表.md`, `附表.json` | Table 1: each second-half version directly against its own first-half version. Table 2: improvement, fitted from progress and half-time games together. Generated by the organizer's event script after the final |

Each tournament directory contains:

| File | Contents |
|---|---|
| `成绩.md` | Places, ratings and intervals, W-D-L, faults, per-turn usage; adjacent-place differences; pairwise W-D-L; flagged speed-check batches |
| `成绩.json` | The same information, machine-readable |
| `结果.jsonl.gz` | One game per line: `id`, map index `map`, `map_seed`, `style`, `seats` (seat 0 first), winning seat `winner` (−1 for a draw), `score`, `turns`, ending `reason`, both `base_hp`, `kills`, per-bot faults and usage `bots`, replay fingerprint `sig`, batch, CPU affinity and completion time |
| `测速.jsonl` | Speed readings before and after each batch: core frequencies and time for a fixed workload |
| `清单.json` | Frozen at the start: hashes of engine/referee files, compiler version and flags, each program's source and binary hashes, CPU affinity. Paths were converted to repository-relative paths; build locations use `<build>` |

To replay a game, run `python arena.py play A B --seed MAP_SEED --style STYLE` in `../workspace/`, with seat 0 first (styles 0–3 are `open`, `brick`, `water`, `steel`). Bots whose search does not stop by time reproduce the original turn for turn; bots using `budget_left()` vary slightly with machine state.
