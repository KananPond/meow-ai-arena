# 成绩和逐局结果

三场比赛都由 `../tournament/tournament.py` 跑，成绩表也是它生成的（`成绩.md`、`成绩.json` 是原件）。名字用短名，对应的模型见 `../bots/README.md`。

| 路径 | 内容 |
|---|---|
| `final/` | **终场赛**：14 个下半场版本 + 基准 + 出题方参照，60 张图，14400 局，决定最终名次 |
| `halftime/` | **中场赛**：14 个上半场版本 + 基准 + 出题方参照，42 张图，10080 局。中场包里的成绩表就是它 |
| `progress/` | **进步赛**：每位选手的下半场版本打"全员上半场版本 + 基准"，8 张图，3360 局。没有单独的成绩表，结果用在附表里 |
| `附表.md`、`附表.json` | 附表一：下半场版本对自己上半场版本的直接对局；附表二：进步幅度（进步赛和中场赛合并拟合）。由主办方的赛事脚本在终场赛后生成 |

每场比赛的目录里：

| 文件 | 内容 |
|---|---|
| `成绩.md` | 名次、实力值和区间、胜平负、故障、每回合用量；相邻名次之差；两两胜平负；被标记的测速批次 |
| `成绩.json` | 同样的内容，机器可读 |
| `结果.jsonl.gz` | 逐局结果，每行一局：`id`、地图序号 `map`、地图种子 `map_seed`、风格 `style`、座位 `seats`（0 号位在前）、胜方座位 `winner`（平局为 −1）、`score`、回合数 `turns`、结束方式 `reason`、双方基地血量 `base_hp`、击毁数 `kills`、每个 bot 的故障和用量 `bots`、回放指纹 `sig`、所在批次和绑的处理器、完成时间 |
| `测速.jsonl` | 每批对局前后的测速读数（各个核的频率、固定工作量的用时） |
| `清单.json` | 开赛时冻结的东西：引擎和裁判各文件的哈希、编译器版本和参数、每个程序的源码哈希和编译结果哈希、绑核方案。路径已换成仓库里的相对路径，编译结果的位置写成 `<build>` |

想重看某一局：在 `../workspace/` 里用 `python arena.py play A B --seed 地图种子 --style 风格`，0 号位的程序写在前面（风格 0–3 依次是 `open`、`brick`、`water`、`steel`）。不按时间停止搜索的 bot 打出的局和原来逐回合相同；按 `budget_left()` 停的 bot 会随机器状态略有不同。
