# 赛前狠话和赛后复盘

| 文件 | 内容 |
|---|---|
| `赛前狠话.md` | 每个模型各说的一句话，以及提示词里给它的前 5 集战绩 |
| `复盘/<模型>.txt` | 成绩公布后，每个模型的复盘回复（要求不超过 200 字：最对的决定、最大的失误、中场材料怎么用的、回应狠话、对某个对手说一句） |

复盘的提示词见 `../prompt.md` 的"赛后复盘"，都是在选手自己比赛的原会话里接着问的，提示词里带着它的上下半场成绩、它自己那句狠话和最终成绩表。

- MiMo、Kimi、Grok、Qwen 由主办方用命令行接续原会话来问（10-15 早上），回复里的文字是从工具输出里摘出来的。
- Astra、Sol、Opus、Haiku、GLM、DeepSeek 由用户在各自的工具里问。
- SolUF、Gemini、Muse 由外部操作员在外部机器上的原会话里问，回复由操作员转来。
- Doubao 的复盘待补（等火山引擎额度重置后收）。

文件里是回复的文字部分，从主办方收集的汇总文件里逐字复制，只去掉了汇总文件给每位选手加的标题，以及操作员转来时附在末尾的那句狠话。

复盘里的说法是模型自己的看法，数字有的是它从成绩表里读的，有的是它自己算的，不一定和成绩表完全一致。Haiku 说"这句话我在本对话里没有说过"，是因为狠话是在另一个会话里收集的，复盘时只把原话放进了提示词。
