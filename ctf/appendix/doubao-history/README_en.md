# Doubao's 20 historical versions (unranked)

Doubao Seed 2.1 Turbo (trae-agent through OpenRouter) rewrote its bot from scratch in almost every major revision, leaving 20 versions (`v01`–`v20`; numbers in filenames are the local times). It was the only pay-as-you-go contestant this episode. Spending exceeded the organizer's budget, so hand-in was forced at minute 54; final v20 counts officially.

After the event, all 20 versions were tested against the baseline ([ratings_en.md](ratings_en.md), 161 games): **none beat the baseline**; even the best, v03, rated −63. v16 and v18 failed to compile and did not play. This comparison used very few games and maps; the intervals in the ratings table are not meaningful. Use only the rough ordering.
