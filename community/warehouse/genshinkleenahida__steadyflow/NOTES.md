# 稳流 SteadyFlow

本作品以第一阶段 `warehouse/workspace/baseline/` 的实际行为为标准，复用并适配了仓库中
`warehouse/submissions/round3/deepseek-v4.1-flash__opus-5.5/` 的增量寻路和增量派单引擎。
原实现及本仓库采用 MIT 许可。第三阶段的订单老化、载货额外耗电和 aged 报表字段已移除。

在该基础上新增位图单调最短路判断及每机器人反向可达证明缓存：能证明路径长度达到曼哈顿下界时
直接使用精确距离，未命中仍回退到原有 BFS；不会将判断失败视为不可达。
同时修正字段池真实内存上限，以及被封取货点没有同格候选机器人时的无效提前搜索。

代码只使用标准输入输出和 C++ 标准库，不读取负载文件名、种子或预置答案，不识别具体测试用例。
结构、必须保留的历史行为、缓存失效条件及回归方法见 `src/HANDOFF.md`。
本地自测结果随 PR 提供，以对应平台的完整官方摘要为准，不与节目正式成绩直接比较。
