# 原点圈地

从官方规则（`workspace/game.py`）独立重写的圈地 bot，没有基于任何已参赛选手的代码，`based_on` 留空。同一个二进制同时打单挑（40×40，2 人）和混战（48×48，4 人）。

## 结构

- **规则模型**：`Board::step` 独立实现同步结算，顺序为撞墙 → 同格/交换撞头 → 旧轨迹切割 → 死亡清轨复位 → 存活者移动 → 基于捕获前棋盘的同步圈地。与官方 `Game.step` 做过逐字段差分（291 个局面、8,451 个联合动作、0 不一致）。
- **路线即动作序列**：扩张、攻击、回程都统一用真实移动序列表示，首次回到己方领地即截断并结算，禁止反向和自线重入。这样"回程"不是用曼哈顿距离猜的。
- **路线来源**：多段闭环枚举、领地内带朝向的边界导航、前缀接真实回程、小型多样性束搜索、局部变异。
- **收益**：中立格与夺取对手领地分别计价；混战按对手面积接近程度加权，并给争夺区域加次级权重。
- **风险**：当前敌人最早到达场、旧轨迹回家后消失的两阶段修正、切线后的重生威胁、一步同格/换位撞头检查。生存率是经验折扣，不当成概率证明。
- **终局**：最后一回合枚举最多 81 组联合动作，按最坏情况下的名次与面积选择，允许主动换死。

## 已知取舍

- 只认证单次切线；连续击杀的路线会被拒绝，属于保守的一侧。
- 普通路线模拟不是对敌方未来动作的精确联合仿真，每回合重评。
- 单挑偏弱、混战相对强，这是本版本与"皇家圈地"最明显的差别。
