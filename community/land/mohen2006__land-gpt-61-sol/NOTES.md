# 墨痕喵

单文件 C++20 bot，同一份程序参加单挑和四人混战。实现由 `gpt-6.1-sol` 在 Codex 中编写；使用标准库，单线程，只读标准输入、写标准输出，不保存跨对局状态。

## 思路

- **精确计算收益。** 将每行编码为 64 位整数，从边界泛洪，计算轨迹闭合后真正得到的格子。对手保护区不计入收益。夺取对手领地的价值高于中立格；混战中额外关注当前领先者。
- **同时考虑多个对手。** 为每个对手计算到达时间，区分“尚未回家”和“回家后旧轨迹已清空”两种状态。闭环方案需要在对手能够碰到暴露轨迹之前完成，并避开下一步可能发生的撞头。
- **持续修订路线。** 搜索两至四段直线组成的闭环，精确复评候选路线，再用少量随机扰动补充五段路线。混战中对实际路线去重，让精确复评覆盖更多不同方案。不同方向交错搜索，保留尚可执行的旧计划，同时比较最短回家方案。单挑时还会围绕当前最优计划调整线段长度，使已经走出的轨迹有机会用更好的路线闭合。
- **机会性切线。** 优先寻找能在对手最短回家时间内抵达的轨迹，估计阻止其圈地的价值。追击还会检查自己的现有轨迹、回程，以及其他玩家和被击杀者重生后的威胁。
- **按混战名次决定追击价值。** 用双方面积差估计各对手影响名次的程度。保住自己的领地单独计入收益，阻止一个对手扩张则按该对手的竞争价值折算；对手之间互相抢地的影响会抵消。混战允许至多四步的额外拦截距离，并按成功机会折扣，且需要在追击未成功时仍有安全回程。能够立即完成圈地时，也会与切线收益比较。
- **限制计算量。** 搜索采用约 7 毫秒的软预算，为通信和系统负载留出余量。临近结束时优先考虑能够及时兑现的面积；路线失效时，使用合法移动和回家距离选择后备动作。

## 参考来源

这是重新编写的实现。阅读并参考了以下官方选手的策略，因此均在 `meta.json` 的 `based_on` 中注明：

- `land/bots/sonnet-5@claude-code#1/bot.cpp`：闭环候选搜索、到达时间约束、位运算泛洪及切线收益的取舍。
- `land/bots/gpt-6-astra@codex#1/bot.cpp`：对手回家后轨迹清空的建模、滚动修订计划及混战中对手价值的区分。
- `land/bots/opus-5.5@claude-code#1/bot.cpp`：闭环后的精确面积评估、攻击与安全回程的联合检查。

## 复测

在仓库根目录运行：

```sh
python land/challenge.py community/land/mohen2006__land-gpt-61-sol/bot.cpp
python community/check.py community/land/mohen2006__land-gpt-61-sol
```

默认挑战的局数较少，搜索的软时间预算也可能使不同机器生成不同候选路线，成绩存在波动。社区自测与节目正式比赛的成绩口径不同。
