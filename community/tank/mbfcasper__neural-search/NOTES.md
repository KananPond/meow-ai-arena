# 神经网络搜索（精简优化与多架构自适应版）

## 概述
本作品为基于深度强化学习网络与联合响应搜索的 Tank Bot（单文件版，大小 261,609 字节，完全符合社区 <= 256 KiB 限制），由 AI（模型：GPT-6.1 Sol + Gemini 4 Argon + Gemini 3.8 Flash + Claude Opus 5.5，工具：Codex / Antigravity / Claude Code）编写与协作优化。在完整保留原有高质量权重与决策精度的基础上，重构了推理算子并引入动态搜索增强与风控微调。

## 核心设计与优化
1. **源码瘦身与合规清理**：
   - 文件大小为 **261,609 字节**（约 255.48 KiB <= 256 KiB 限制）。
   - 彻底移除了未调用的辅助函数（包括 `load()`、`teacher_score`、int8 路径等），源码扫描无任何 `fopen` 或外部依赖告警。
   - 命名空间与结构规整，内嵌 Base85 权重无三字符组分割。
2. **多架构 SIMD 算子加速**：
   - 实现 AVX-512（FMA 累加）、AVX2 与标量（Scalar）三级算子，自动检测并支持环境变量 `TANK_SIMD` 控制。
   - 前向推理中跳过零输入（Zero-input skip），首次调用时构建导航图并在多步展开中共享 Context 与 proposal 缓存。
   - 320 局整轮对战时间进一步大幅压缩至 **119 秒**。
3. **搜索与策略增强（Tune）**：
   - **Risk 微调（0.15）**：引入适度悲观风险加权，有效压制极端对局中的突发被抓反杀。
   - **Ladder 阶梯爬升**：首回合测速后，在 4 批次时间内逐步提高根节点与搜索深度（(6,4) -> (6,5) -> (8,5) -> (8,6)）。
   - **Prune 剪枝替换**：保留候选备选池，第 2 轮起若候选落后领先者超过阈值，自动替换为备选候选继续推演。
   - **Extra 启发式补充**：根节点 >= 4 时，在贪心基础动作后紧跟启发式 proposal 与低危险度动作候选。
   - **Opp 对手建模预测**：逐回合对比 3 种对手预测偏差，使用衰减权重动态调整反向模拟。
