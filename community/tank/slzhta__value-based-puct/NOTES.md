# value-based PUCT

作者：slzhta  
开发方式：人和 AI 协作；使用 GPT-6 Astra，开发工具为 Codex。

这是一个结合规则评估、PUCT 搜索和轻量神经网络的坦克组队程序。目标是在每回合有限的 CPU 时间内，同时考虑三辆坦克的争夺资源、进攻、回防与局部交战。

## 代码来源

程序基于本仓库公开的 `tank/tournament/sparring.cpp` 改进，保留并扩展其地图评估、动作先验与角色分工；开局协调参考了官方 GPT-6 Astra 实现。源码保留了上游 MIT 许可与来源说明。

开发中还使用官方选手、自己的历史版本，以及 mbfcasper 的社区作品[《神经网络搜索（自适应预算版）》](https://github.com/chen-006/meow-ai-arena/pull/16)作为对照及部分训练对局的参与者。本程序的 actor 和 value 权重通过下述离线流程训练。

## 搜索与协同

程序使用官方 `tank::step` 推演确定性状态，以每辆坦克的局部状态组织搜索节点，缓存动作先验和统计信息，并通过 PUCT 在当前高价值动作与尚未充分探索的动作之间分配搜索量。

开局分配尽量减少己方坦克争抢同一处补给；搜索保留规则提供的角色和目标信息。己方与敌方各车的动作都参与搜索，并使用相应统计信息更新动作选择。

## 两个轻量网络

- **Actor：** 使用 `160 → 32 → 25` 的小型网络，对根节点各坦克的动作先验进行修正。网络得到的先验与规则先验各占 50%。仅在根节点计算，深层节点仍使用规则先验，以控制计算开销。
- **Value：** 使用共享的 `64 → 32 → 1` 网络，从双方视角构造对称的局面估值。64 个输入槽位中有 57 个有效特征，其余为零填充。非终局叶子将规则估值与网络估值按 65% / 35% 混合；终局直接使用实际胜负。

全部权重以常量形式内嵌在 `bot.cpp` 中，由 C++ 完成推理。

## 离线训练

Actor 通过离线搜索产生的动作分布训练；value 的主要监督信号来自完整对局的最终胜负，并加入对已有 value 预测的约束。训练过程使用 PyTorch，实际比赛只执行 C++ 推理与搜索。

本次 value 微调使用 16,384 条对局轨迹，覆盖 7,635 张不同地图，包含历史对局和新增的多策略对局。训练、验证与测试按地图隔离，并检查种子与地图几何，避免同一地图跨集合出现。

模型从已有 value 权重继续训练，最多进行 12,800 次参数更新，按验证集 value 误差选择检查点，再通过对战评估实际表现。

## 运行预算

源码只依赖官方 `tank.hpp` 与 C++ 标准库，由官方主循环调用 `init` 和 `decide`。程序单线程运行，网络权重固定，搜索状态保存在当前对局的内存中。

搜索以 CPU 预算作为停止条件，并预留返回和裁判交互的时间；首回合内部搜索截止约为 24ms，后续约为 38ms。官方评测预算为首回合 2000 CPU ms、之后每回合 50 CPU ms，实际搜索量随机器及运行负载变化。

## 验证与已知局限

已通过官方 `community/check.py` 的结构检查、编译与正式模式对战。评测覆盖 14 个官方选手、出题方参照和基准，每个对手 20 局，共 320 局，本地战绩为 313 胜、0 平、7 负。逐对手成绩与运行环境见配套的官方自测摘要。

开发中的额外对战用于比较搜索与网络配置；社区榜成绩由合并后的 GitHub 自动评测生成。

当前搜索视野有限，深层搜索沿用部分根节点战略信息。后续重点是改善远距离回防与长期资源交换的判断，并通过更广的地图、策略覆盖和更均衡的采样提高 value 的泛化能力。
