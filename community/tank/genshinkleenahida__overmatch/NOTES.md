## 公开状态转移与资源节奏

内置策略只使用公开 `State` 和本局历史，预测敌方完整三车 `Orders`。下一回合以我方最终实际返回的命令调用规则模型，核对整份观测 `State`；所有能产生该观测的官方合法命令别名都计入未知类的似然，使用对数运算保留有限的未知权重。

采样到已知模型时，仅在搜索根节点强制该模型的完整敌方命令；更深层继续使用原 PUCT。被强制的敌根动作不计入其对抗选择统计。某个模型算不完时，只将该模型的权重转入未知类，不伪称观测已经反驳它。最终友伤检查使用最大后验模型的完整三车预测；未知类在概率相同时优先。

未知类的观测似然按官方合法联合动作均匀计算，而未知分支规划使用原 PUCT，两者并不相同。因此这里的置信度是近似模型权重，不是校准后的对手身份概率，也不是 纳什 均衡或全局鲁棒性证书。实际限时对手可能走过与内置副本不同的计算截止路径。

当基准策略是已验证的最大后验假设时，FIRE 可以不等待其原补给任务而直接进攻。这利用了基地每回合限伤：同一回合多发命中仍至多扣1 HP。程序不使用种子表、外部对手名称或按平台选择策略的分支。

## 有限预算下的完整动作与预取

在可选的对手推断之前，先构造一份完整合法的原生保底命令。如果辅助计算耗尽内部额度，或没有完成一条完整轨迹，就沿同一最终友伤检查与记忆路径返回保底命令。对可立即射中1 HP队友的情况，执行一次有界的完整联合动作坐标改进：先比较终局胜利，再比较生存，最后按原价值打破平局。这修复了辅助计算耗尽后直接三车不动的问题，没有改变正常六步搜索目标。

首回合最终实际命令冻结后，利用首回合的剩余额度，为每个仍可成立的模型预取一次下一根预测。期望状态只由当前公开 `State`、已冻结的我方最终 `Orders` 与该模型的当前预测得到。真实下一根先执行正常观测过滤，再仅在整份 State 与座位均匹配时复用缓存；缓存只消费一次，不重复推进私有历史或随机数状态。

已经尝试但未完成、或期望状态不匹配的预取，按计算不可用处理，不伪称观测反驳；尚未尝试的模型仍可正常调用。`init` 会清空缓存。

## 规则与计时

生产源码只包含官方 `tank.hpp` 和标准库，没有自定义 `main`，不在运行时读写文件、联网、启动其他进程或线程，也不重置官方预算。官方预算保持启动、初始化及首回合合计2000 CPU毫秒，之后每回合50 CPU毫秒。

后续回合的内部总目标为32毫秒，包含前置动作、模型推断与搜索。首回合原生阶段计入前置与初始化成本，在辅助计算时间之外保留24毫秒搜索目标；命令冻结后的预取单独计入同一次官方首回合总预算。

预取使用从根起点算起600毫秒的合作式界限；每次调用模型前检查真实剩余预算的64毫秒返回余量，模型可见的私有剩余额度为 `min(真实剩余-8, 50-该模型已用时间)`。这些都是合作式检查，不是抢占式控制，也不构成严格最坏执行时间保证。官方计量起点不会重启；中止的未完整轨迹直接丢弃，不回传部分价值。非默认参数下，对手模型停用，规划走原生回退，专门化模拟也回到官方结算。

## 破砖动作支持

若一块砖后的首辆敌车，在现有六回合规划视野内满足保守的炮弹行程与装填界限，原生射线可以保留这类准备射击。它补回原筛选遗漏的一类动作，不是强制击毁证明；规则结算、评分目标、权重和官方规则不变。独立回放中的固定命令物理反事实与可达状态 ASan/UBSan 检查均已完成，范围与原始证据分别保留。

## 完整联合终局胜利证书

原控制器先完成友伤检查并记住最终命令。敌基地剩1点生命值时，可选检查器先验证这份命令，再枚举原始 State 的我方完整官方 规范代表 合法联合动作。每个候选都从同一份 State 复制，调用官方完整 `tank::step_as`，检验敌方全部 规范代表 合法联合动作。

只有实际遍历数量等于完整正数笛卡尔积、每个结果均满足 `done && winner == me`，且最终 截止谓词 检查仍允许工作，才替换原命令。官方 SDK 保证 规范代表 代表在其他五车任意命令下保持最终 State 效果，因此这里没有按模型预测缩小敌动作域。这是当前回合的全称胜利条件。

一个典型缺口是友军 FAST 同回合先离开炮线，随后 FIRE 子弹穿过原位置，摧毁敌基地最后1点生命值；按当前占格逐车筛选会漏掉这种配合。近敌截弹、移动争格、同时毁基地与最终截止失败均有官方规则用例。一个动作被反驳，不表示其他联合动作也无解；验证期间输入 State 与所列模型、随机数、历史和缓存快照保持不变。

任意反例只拒绝该候选；任意 截止谓词 失败则中止整次可选检查，原样返回本次终局检查开始时的原控制器最终命令，绝不提交半份证明。额外额度为合作式 `min(4 CPU毫秒, 官方剩余-8毫秒)`，不重置官方计量器。认证后直接返回确切被认证的三车命令，不再做友伤修补；成功替换只更正 `our_last` 与导出的耗时记录，不第二次调用 `remember` 或预取。

检查器刻意不完备：它不保证整局安全、严格最坏执行时间、限时搜索强度不下降，也不能由检查中止推出没有胜法。它不能直接修复敌基地从未降至1点生命值的旧轨迹。原控制器只重命名最后全局 `decide` 后追加检查器，逆向处理可逐字节恢复破砖父版；这项源码属性并不保证限时可执行程序的每次搜索路径或成绩相同。

## 社区分数的含义

社区 CI 使用未修改的默认320流程重新计算榜分；FULL1280是另一套额外完整评测。两者都沿用固定终场赛对手评分，只拟合投稿自身的 Bradley–Terry 实力值，并保留官方虚拟平局；基准为0，胜负赔率强10倍记+400。参照名次把投稿插入十四位历史 AI 的固定评分，没有重跑他们之间的终场赛；它不等同于正式赛名次，也不保证未来所有地图全胜。

最终目录只包含 `bot.cpp`、`meta.json`、`NOTES.md`。提交时应以中文稿实际社区检查的完整摘要、对应源码哈希及最终三文件快照为准，不能用原版 FULL1152.0466替代社区320摘要。
