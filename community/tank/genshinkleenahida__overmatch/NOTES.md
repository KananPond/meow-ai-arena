# Overmatch（超越火力）

本次更新在已合并的 R5 投稿上继续完善对手预测、三车协同和有限预算下的搜索。保留分车 PUCT、原预训练动作／价值网络及 R5 的一回合终局证书，扩充为十二份公开策略的统一转移后验，加入完整联合指令支持、安全追猎、共享基地限伤评价与旧弹风险处理，并恢复默认参数的专用模拟。

投稿源码固定为 R13：SHA256 `628a67a5845de0d8a99df35273a9b9bc63d524e77d8b30bf8524846dd27ea7e3`，261694 字节，距 262144 字节上限 450 字节。代码保持受测原字节，未混入后续诊断原型；首 3196 字节的原版权、许可与来源说明保留。作者及 GitHub 账号为 genshinkleenahida，采用 MIT 许可。

本源自己的 FULL1280 为 1280 胜、0 平、0 负，固定参照实力值 1152.0466205881；回归与跨平台集合仍有五次有效负局，因此不能宣称全套不败。下文保留完整结果及异常。本次最终三文件在最新主分支上的正式自测，以同次 PR 的官方摘要和独立结果报告为准，不用历史分数代填。

## 搜索与十二策略转移后验

战斗层沿用 slzhta 的分车 PUCT 和原 actor/value 网络。完整的非终局六步推演仍使用 65% 压缩后的路径平均规则值与 35% 末状态神经值；终局胜、平、负直接覆盖估值。未完成推演不回传，辅助计算不足时仍保留合法完整的三车 Orders。没有新增训练、量化或替换网络权重。

十二份公开策略从同一公开 State 预测敌方完整三车 Orders。下一回合把上一公开 State、实际己方完整 Orders 和各模型的敌方预测送入物理转移，与完整观测 State 比较，更新统一后验。保留 unknown 类；它以均匀合法联合指令的转移相容比例作为置信代理，不把模型名称、赛程信息或已知测试种子当作输入，也不按历史败局坐标增加特判。

这种后验描述的是公开策略与当前轨迹的相容性，不是已校准的身份识别概率。采样到完整的已知模型时，只在搜索深度零约束其敌方根 Orders，更深层继续使用原 PUCT；不能据此声称全程准确预测、纳什策略或整场必胜。最终友伤过滤使用完整的最大后验预测，同概率时优先 unknown。模型因计算不足而不可用时，对应的概率份额转入 unknown，不伪称观测已经反驳了它。

## 首回合预取与预算完整性

首回合先固定最终己方完整 Orders，再让各公开模型在其预测的下一公开 State 上预取，利用首回合较宽的计算预算。各模型使用独立的 50 毫秒私有预算视图，但官方计量器从未重置。

下一真实根只在完整 State 与座位吻合、预测完成且尚未消费时使用缓存一次，避免重复推进模型历史和随机数。已经推进但失配、未完成或无法消费的模型转入 unknown。此处核对完整状态，不仅比较回合、位置或基地血量。

限时预测的完整性由实际截止分支与预算共同约束。SolUF 仅在 18、7、5 毫秒对应的实际提前中止分支置不完整标记；纯预算读取不再因为读到低于 18 毫秒而自动置标记。Muse 保留其实际提前返回分支的完整性标记。其他公开限时模型仍可能因计算前缀不同返回不同动作，不能从同源码、同配额推出跨机器完全相同的预测。

官方预算保持首回合 2000、之后每回合 50 CPU 毫秒。后续内部总目标仍为 32 毫秒，并保留 8 毫秒返回余量；辅助预测与过滤计入同一真实额度。完成性检查、完整候选回退和余量是工程约束，观测最大耗时不是严格最坏执行时间证明。

## 完整联合指令支持与安全追猎

分车搜索可能各自推荐一个高访问动作，但拼接出的三车 Orders 从未作为完整样本回传。新增联合支持只登记真正完成回传的根三车 Orders，按实际出现次数、己方回报和及固定编码破同分。原边缘推荐已有完整联合支持便保留；只有零支持时才投影到实际样本中的众数。没有完整样本时保留原候选。后续友伤与终局过滤仍可能改变输出，不能把最终命令一概称作有搜索样本支持。

安全追猎用于 rollout 中一个有限替换点：已有追猎任务、开局阶段结束、当前 HP 大于 1，且原动作是对非任务近敌的炮击时，才尝试替换为严格降低任务距离的单步。目的地必须为空地且无人；检查争格、旧弹两个子步与对穿、其他坦克可发新炮的两步到达，以及敌方到期复活的 telefrag。已有弹触达当前基地／友军或原炮背后的当前防卫职责会否决替换。

这项局部检查只约束被替换车辆一个完整回合的到达、伤害与复活冲突，不证明未来全队安全。它也不是每个真实根回合都运行的追猎控制器；PUCT、开火早返回及最终过滤仍决定实际输出。

## 基地限伤、攻击覆盖与自弹风险

默认规则下，每座基地在一个完整回合内共享一血命中容量。静态八格旧弹估值按目标基地和预计到达回合归桶，预计到达时间使用两个子步的完整回合尺度；同一桶不按炮弹 owner 重复奖励。非默认参数保留回退。这个近似没有完整表示未来移动、弹道抵消、拆墙、新炮、有限 HP 与终局截断。

最小攻击覆盖最多枚举三车的七个非空射手子集，在默认且未终局状态下，让敌方静止，比较六回合敌基地 HP 前缀及终局分类，寻找与全部候选射手相同的覆盖。己方终局胜利允许成为吸收状态；参考轨迹敌胜、平局或计算未完成时回退。结果用于角色分配，不能保证释放出的车辆最终一定移动，也不是对动态敌方的持续吞吐保证。

旧自弹风险评价在默认、同向八格内地形通向己基地时，不把当前敌车当作永久挡板，也不给被跳过敌车假想命中收益。友军挡板等其他近似仍保留，可能过罚，不是未来伤害上界。当前回合的基地友伤反事实则固定一份完整敌方 Orders，用官方一步结算和整 State 比较隔离本回合有害自基地炮；它不能撤回旧弹，也不证明所有敌响应下的长期支配。

## 有限的一回合终局证书

沿用 R5 的终局证书：敌基地只剩 1 HP 时，按官方合法命令代表枚举完整联合动作。只有某份己方三车 Orders 对完整敌方三车合法命令笛卡尔积中的每一个响应，都在官方一步结算后满足 `done && winner == me`，才接受证书。完整遍历数量与最终截止检查也必须通过；截止便整次回退，不接受部分遍历。

证书额外工作限制在最多 4 CPU 毫秒及剩余 8 毫秒余量内。它只证明当回合的全称胜利条件，不能发现或证明所有多回合获胜路线，也不保证每次存在证书时都能在时限内找到。
